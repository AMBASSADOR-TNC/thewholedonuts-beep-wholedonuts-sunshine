# Repository Work Workflow

Use this path for all future repository work.

1. Start from the latest `main` (`git fetch origin`, then branch from `origin/main`).
2. Make a real, reviewable change; open a pull request only when there is one.
3. Preserve all project files, Git history, repository ownership information, and intellectual property. Do not delete or overwrite existing material, and do not rewrite history.
4. Keep `WD.INPUT`, `WD.OUTPUT`, and `WD.ARCHIVE` records as described in their READMEs.
5. Never commit or publish private account-inventory data, credentials, or secrets. Use `.env.example` placeholders only.
