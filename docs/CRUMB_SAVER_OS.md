# Crumb Saver OS (ALLCRUMBS-∞)

Preserved from the public `Whole-Donuts` repository (`os/crumbs-all.md`). The detailed pipeline, loop, vault, code-engine and saver notes are in the same source, under `os/`.

The Crumb Saver OS is the complete, unified system that captures, stores, moves, evolves, transforms, and integrates every crumb inside the Whole Donuts ecosystem. It contains the Vault, Pipe, Loop, Code Engine, Flow Engine, Map, and Fusion Layer.

## 1. Crumb Vault (CV-∞)

Permanent memory chamber.

Stores: ideas, drafts, sparks, fragments, helper concepts, domain seeds, movement language, micro-product sketches, unfinished thoughts.

Behavior: never deletes, never loses, never closes, always resurfaces, always evolves.

## 2. Crumb Pipe (CP-7)

Movement engine. Stages: 1. Capture, 2. Tag, 3. Sort, 4. Shape, 5. Build, 6. Route, 7. Deliver.

Output: helper actions, micro-products, domains, OS modules, donor flows, movement language.

## 3. Crumb Loop (CL-∞)

Circulation engine. Cycle: 1. Surface, 2. Review, 3. Shape, 4. Route, 5. Build, 6. Integrate, 7. Return.

Behavior: never stops, never stagnates, never loses crumbs, evolves everything.

## 4. Crumb Code Engine (CC-0)

Automation specification layer (specification only, no executable code). Future structures: crumb object, pipeline functions, loop functions, vault storage functions, routing functions.

Principles: non-destructive, reversible, expandable, lane-aware, domain-aware, OS-aware.

## 5. Crumb Flow Engine (CFE-∞)

Defines how crumbs move across the OS. Flow types: linear, cyclical, omni-directional, cross-lane, cross-domain, deepening, stabilizing.

## 6. Crumb Map (CM-28)

Maps crumbs to the 28-domain ecosystem (see `description-28.csv`):

- identity crumbs → WHNUTZ
- community crumbs → Sunshine
- routing crumbs → ACCESS
- domain crumbs → 28-domain grid
- donor crumbs → DCE
- OS crumbs → WD-OS

## 7. Crumb Fusion Layer (CFL-7)

Unifies crumbs across all subsystems. Fusion points: Vault ↔ Pipe, Pipe ↔ Loop, Loop ↔ Code, Code ↔ OS, OS ↔ Domains, Domains ↔ Helpers, Helpers ↔ Vault.

## 8. Crumb Engine (CE-1)

The master engine. Responsibilities: capture, tag, store, move, evolve, transform, integrate, archive, resurface.

## 9. Crumb OS Integration (COI-∞)

Connects crumbs to the Whole Donuts Operating System: Identity System (WHNUTZ), Community System (Sunshine), Routing System (ACCESS), Domain System (28-domain map), Donor System (DCE), OS System (WD-OS).

## Public boundary

This is a design description. The public site has no crumb submission endpoint; submitted material must be original or permitted, reviewed, and free of private, identifying, financial, health or legal information (see the `CRUMB_PROTOCOL.md` in the `wholedonuts-universe` repository).
